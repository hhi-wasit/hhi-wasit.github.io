HHI Wasit Website Deployment

Upload the contents of this package to the new repository. The hero background is loaded from:

  hero/herobg.jpg

To change the hero background later, replace that file with a new image using the exact filename herobg.jpg. Keep the image inside the hero folder. The restored GitHub Pages deployment workflow is located at:

  .github/workflows/static.yml

The package intentionally excludes Git history and local temporary files.
